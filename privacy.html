Privacy Policy — Muse YouTube

Last updated: October 30, 2026

Muse YouTube is a private, single-user application operated by Charles Thomas II for managing his own YouTube channels (The Fun Gang, Agent Income Lab, On The Record Bodycam, and Charles Thomas @cdt41). It is not offered to the public and has no other users.

Data accessed

With the channel owner's explicit OAuth consent, the application accesses YouTube Data API v3 and YouTube Analytics API data for the owner's own channels only: channel and video metadata, playlists, upload functionality, and channel analytics (views, watch time, subscriber counts, estimated revenue).

How data is used

Data is used solely to upload and manage the owner's own videos, organize playlists, edit the owner's own video metadata, and report the owner's own channel performance back to the owner. No data is sold, shared with third parties, used for advertising, or used to train machine-learning models.

Data storage and protection

OAuth refresh tokens are stored locally on the owner's private computer in a permission-restricted folder (file mode 0600), never in cloud storage, source code, or logs. Access tokens are short-lived and held in memory only.

Data retention and deletion

Tokens remain stored only while the owner uses the application. The owner can revoke access at any time from his Google Account permissions page or by deleting the local token files, which immediately ends all access.

Limited Use disclosure

Muse YouTube's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including its Limited Use requirements.
