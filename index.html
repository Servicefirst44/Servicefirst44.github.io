Transformed Minds

Transformed Minds is a private, single-user application operated by Charles Thomas II to manage his own YouTube channels: The Fun Gang, Agent Income Lab, On The Record Bodycam, and Charles Thomas (@cdt41).

The application uses the YouTube Data API v3 and the YouTube Analytics API, with the channel owner's explicit consent, to:

  • Upload the owner's own videos to his own channels
  • Edit the owner's own video titles and descriptions
  • Organize the owner's own playlists
  • View the owner's own channel analytics (views, watch time, subscribers, estimated revenue)

The application is not offered to the public, has no other users, and never accesses any other person's YouTube account or data.
